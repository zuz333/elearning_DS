# DILAPAN-S learning hub

Static one-page e-learning prototype for healthcare professionals.

## Files

- `index.html` — page structure and content
- `styles.css` — responsive styling using HCP brand colours
- `script.js` — mobile menu and 10-question interactive knowledge check
- `assets/` — place approved PDFs here and update the links if filenames differ
